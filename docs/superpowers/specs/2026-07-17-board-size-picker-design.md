# 놀이판 크기 선택 기능 설계

날짜: 2026-07-17

## 목적

고고전진 놀이판의 표 크기가 5행 7열로 고정되어 있다. 사용자가 행/열 수를
직접 골라(예: 4×4, 5×5) 표 크기를 바꿀 수 있게 한다.

## UI

- 소리 버튼이 있는 `.sound-bar` 줄의 **왼쪽**에 드롭다운 2개를 배치한다:
  `행 [5▾] × 열 [7▾]`
- 각 드롭다운은 1~10 범위, 기본값은 행 5 / 열 7 (현재와 동일).
- 스타일은 기존 노란 버튼·파스텔 테마와 통일한다.
- 모바일(640px 이하)에서는 소리 버튼과 함께 가운데 정렬로 줄바꿈한다.

## 동작

- 드롭다운 값이 바뀌면 A팀·B팀 표를 모두 새 크기로 다시 생성한다.
- `grid-template-columns: auto repeat(N, 1fr)`은 JS에서 열 수에 맞춰
  동적으로 설정한다.
- 표를 다시 만들면 기존 동그라미는 초기화되고 개수 표시도 0으로 리셋된다.

## 구현 범위

- `index.html` 단일 파일 수정 (HTML 마크업, CSS, JS의 `ROWS`/`COLS` 상수를
  변수화하고 `buildBoard`가 기존 내용을 비우고 다시 그리도록 변경).
- 테스트 인프라가 없는 정적 페이지이므로 브라우저에서 직접 동작 확인한다.
