# 놀이판 크기 선택 기능 설계

날짜: 2026-07-17

## 목적

고고전진 놀이판의 표 크기가 5행 7열로 고정되어 있다. 사용자가 행/열 수를
직접 골라(예: 4×4, 5×5) 표 크기를 바꿀 수 있게 한다.

## UI

- 소리 버튼이 있는 `.sound-bar` 줄의 **왼쪽**에 드롭다운 2개를 배치한다:
  `행 [5▾] × 열 [7▾]`
- 각 드롭다운은 1~10 범위, 기본값은 행 5 / 열 7 (현재와 동일).
- 스타일은 기존 노란 버튼·파스텔 테마와 통일한다.
- 모바일(640px 이하)에서는 소리 버튼과 함께 가운데 정렬로 줄바꿈한다.

## 동작

- 드롭다운 값이 바뀌면 A팀·B팀 표를 모두 새 크기로 다시 생성한다.
- 표를 다시 만들면 기존 동그라미는 초기화되고 개수 표시도 0으로 리셋된다.

### 섹션 크기 고정 (2026-07-17 추가)

- 팀 카드(섹션)의 크기는 행/열 수와 무관하게 **5행 7열 기준 크기로 고정**한다.
- 표 영역 높이를 5×7일 때의 높이로 고정하고, 칸 한 변은
  `min(가로에 맞는 크기, 세로에 맞는 크기)`로 계산해 정사각형을 유지한다.
- 그리드는 고정된 영역 안에서 가로·세로 가운데 정렬한다.
- 행 번호 원과 글자 크기는 칸이 작아지면 `min(기본 크기, 칸 × 비율)`로
  함께 줄어든다 (CSS 변수 `--cell`).
- 창 크기가 바뀌면 resize 이벤트에서 레이아웃을 다시 계산한다.
